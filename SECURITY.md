# Security policy

Do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected version, reproducible steps, impact, and the smallest safe proof needed to validate the issue. Do not include live credentials, personal information, customer data, or destructive demonstrations.

This project currently publishes design contracts and local analysis tooling rather than a hosted service. Security-relevant design concerns—including authority boundaries, AI mutation rights, auditability, and recovery—are still in scope for responsible reports.
